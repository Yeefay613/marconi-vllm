# Marconi: Prefix Caching for the Era of Hybrid LLMs

This repository contains the source code implementation of the [MLSys '25](https://mlsys.org/) paper [Marconi: Prefix Caching for the Era of Hybrid LLMs](https://arxiv.org/abs/2411.19379). 

## Getting Started

Marconi is implemented in Python. We have tested Marconi on Ubuntu 22.04 with Python 3.11.9.

Detailed instructions on how to reproduce the main results from our MLSys paper are in [artifact_evaluation.md](artifact_evaluation.md).

## KV/SSM Prefix Cache Benchmark

`prefix_cache_benchmark.py` is a standalone trace-driven simulator for investigating KV-cache and SSM-state prefix-cache hit rates without running Marconi's eviction policies. It accepts the same JSONL request traces generated by `utils/generate_trace.py`.

Run a quick built-in sanity check:

```bash
python prefix_cache_benchmark.py --self-test
```

Run ShareGPT traces and write CSV results:

```bash
python prefix_cache_benchmark.py \
  --trace traces/sharegpt_sps=1_nums=100.jsonl \
  --capacity-gb 1 2 5 10 \
  --kv-cache-fraction 0.25 0.5 0.75 \
  --kv-block-size 16 32 \
  --ssm-checkpoint-interval 16 32 64 \
  --output results/prefix_cache_benchmark_sharegpt.csv
```

`kv_cache_fraction` assigns that fraction of the total memory budget to KV blocks; the remainder is assigned to SSM checkpoints. The CSV reports `kv_only`, `ssm_only`, and `hybrid_intersection` rows so cache hit rates can be compared under the same memory split.
